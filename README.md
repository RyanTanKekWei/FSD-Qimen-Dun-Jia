# Qi Men Dun Jia English Website

Public-ready static Qi Men Dun Jia web application based on the validated v35 version.

## Structure
- `index.html` — main website
- `css/style.css` — styling
- `js/qimen.js` — calculator and chart rendering

## Deployment
Upload these files to a static web host such as GitHub Pages, Cloudflare Pages, Netlify, or your own web server.

No server-side database is required for the current calculator.
